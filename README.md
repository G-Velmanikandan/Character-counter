# Real-Time Character Counter

A simple web application built with HTML, CSS, and JavaScript that allows users to type messages in a text area while tracking character usage in real time.

## Features

* Real-time character counting as the user types
* Displays characters typed and remaining characters
* Enforces a maximum character limit (200 characters)
* Prevents input beyond the allowed limit
* Shows a warning message when the limit is reached

## Technologies Used

* HTML5
* CSS
* JavaScript

## How It Works

1. Enter text in the text area.
2. The character counter updates instantly.
3. The application displays the number of characters used and remaining.
4. Once the maximum limit is reached, further input is blocked and a warning message is displayed.

## Example

* Character limit: 200
* Display format: `200/200 characters`
* Warning: `Character limit reached!`
